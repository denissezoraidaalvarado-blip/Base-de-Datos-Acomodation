Creación de Querys
Este repositorio contiene un conjunto de consultas SQL diseñadas para gestionar un sistema de alojamiento turístico, 
incluyendo propietarios, alojamientos, huéspedes, reservas, pagos y reseñas.
Consultas implementadas.
Usar WHERE en UPDATE y DELETE
Validar con SELECT antes de modificar datos
Utilizar alias (a, b, g) en JOIN
Crear índices en claves foráneas
Evitar SELECT * en producción
Usar LEFT JOIN para detectar datos faltantes
